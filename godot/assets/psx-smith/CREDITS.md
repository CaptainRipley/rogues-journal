# Smithy props

The Closed Fist uses these tools. The building itself is still the Going Medieval stone shell, red roof, stone door, and chimney (see `godot/assets/psx-buildings/CREDITS.md`).

Textures that shipped with the smith blend were not in the download, so the meshes are flat unshaded colors. That keeps the yard in the same matte PSX look as the houses.
